# piratenets-pytorch
Independent, MIT-licensed PyTorch reimplementation of PirateNets (arXiv:2402.00326)
and the Expert's Guide training pipeline (arXiv:2308.08468). Download the papers in papers/ (gitignored).
The official jaxpi code's license forbids redistribution, so do not copy any code. Hyperparameter values and design decisions may be taken from jaxpi; never directly copy its library code.
Goal: reproduce the Expert's Guide Allen–Cahn ablation (Table 2).
Reference data: data/allen_cahn_ref.npz (generated by data/generate_allen_cahn.py).
Compute is Google Colab: try to always write most of the code and then provide me with a resource to run your desired thing on Google Colab.
